## “$/GPU/hr”和“$/hr total”是两个价格，别只看前一个

Edgevana 的配置表里，同一行会出现两个时价。以 96 核、504GB 内存、6338GB SSD 那档为例，标的是 $0.47/GPU/hr，同一行右边写着 $4.25/hr total——相差 9 倍。前者是把整台机器的钱摊到每张卡上，后者才是你每小时实际要付的金额。

同样的口径问题在这些配置上都能看到：

- $0.50/GPU/hr 对应 $1.00/hr total，差 2 倍
- $0.85/GPU/hr 对应 $1.70/hr total，差 2 倍
- $0.69/GPU/hr 对应 $1.38/hr total，差 2 倍

按小时计费时，只盯着“每 GPU 每小时”的数字，总价会低估一半以上；差 9 倍那种配置，低估得更离谱。LightLayer 的整机方案没有这个问题，它直接标整台月价，但代价是你得自己除以 8 才知道单卡成本。

所以“包月一定更划算”这句话不成立。美元计价的裸金属方案，包月买到的是稳定性；人民币计价的虚拟化云主机，包月才真的省钱。

## 24GB 显存够不够，什么活不该用 4090

RTX 4090 的基准显存是 24GB，Edgevana 和算力云的多数配置都标这个数。Edgevana 有部分配置标成 48GB，甚至同一个 SKU 号对应 24GB 和 48GB 两种规格，从公开页面看不出这是多卡机型、特殊版本还是录入问题。选型时按 24GB 算，别把 48GB 当卖点。

厂商对这张卡的定位说得很直接：适合 AI/ML 负载，包括 LLM 训练、微调和推理，裸金属单租户、完整 GPU 利用率、没有虚拟化开销、没有 noisy neighbors。这是厂商自述。对比之下，算力云是虚拟化云主机，平台自述按量付费精确到秒级、可随时释放资源、竞价实例可能被中断。

24GB 够不够，取决于你的模型、精度和 batch size，没有一张通用对照表能替你回答。有一个稳妥办法：先用小时计费开一台，把真实的显存占用跑出来，再决定要不要签月付。跑两三天的小时费，比选错一档整机一个月的差价便宜得多。

有一种情况 4090 直接排除：你需要单卡 48GB 以上的显存。24GB 就是这张卡的上限，加钱也变不出来，只能换型号。
